# FinTrack React

Application de gestion financière créée avec React + Vite.

## Prérequis

Node.js doit être installé. Téléchargez-le ici : https://nodejs.org (cliquez sur "LTS")

## Installation

```bash
# Ouvrez un terminal (CMD ou PowerShell) dans ce dossier, puis :
npm install
```

## Démarrage

```bash
npm run dev
```

L'application sera accessible à l'adresse : http://localhost:5173

## Construction pour production

```bash
npm run build
```

Les fichiers de production seront dans le dossier `dist/`.
